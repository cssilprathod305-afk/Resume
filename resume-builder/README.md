# ResumeForge — Resume Builder

A Canva-style live resume editor built with React, Tailwind CSS, and lucide-react.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Requirements

- Node.js 18+ (Node 20 recommended)
